Step-by-Step Execution Checklist

Starts both MySQL 8.0 (with automatic schema & seed data initialization) and the Spring Boot application container: 
docker compose up --build -d
# Open http://localhost:8080 in your browser

Create the database in MySQL and launch Spring Boot via Maven: 
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS snippet_manager_db;"
mvn clean test
mvn spring-boot:run

Execute unit and MockMvc controller tests using the H2 test profile, and import postman/Reusable_Code_Snippet_Manager.postman_collection.json into Postman: 
mvn test
